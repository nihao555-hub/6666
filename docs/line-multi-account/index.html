LINE 拿密钥：照着点就行

5 个号就做 5 遍。每个号只要复制 2 个密钥，再填 1 个网址。

1 打开 developers.line.biz/console，点进这个账号的 Messaging API 卡片。

2 点顶部 Basic settings，找到 Channel secret，点复制。同页的 Channel ID 也可以记一下。

3 再点顶部 Messaging API，找到 Channel access token (long-lived)，点 Issue，再复制 token。

不要随便再点 Issue。再点一次，旧 token 立刻作废。

4 还在 Messaging API 这一页，往下找到 Webhook：

点 Edit，填下面这个地址（把「你的域名」和数字换成这个号的），再点 Update。

1 号：https://你的域名/webhook/acc1
2 号：https://你的域名/webhook/acc2
3 号：https://你的域名/webhook/acc3
4 号：https://你的域名/webhook/acc4
5 号：https://你的域名/webhook/acc5

然后点 Verify，看到 Success。最后把 Use webhook 打开。

5 同一页把 Greeting messages、Auto-reply messages 关掉，不然官方账号会自己回消息。

做完一个号，换下一个 channel，从第 1 步再来一遍。
