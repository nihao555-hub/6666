A Auto Shoper使用说明
开通 店铺 默认 概览 投料 草稿 队列 红线

跟着黑圈数字点就行

人只出依据，其余字段交给 AI，目标上架信息质量分 5.0。侧栏永远只有 5 项：概览 → 店铺 → 投料 → 草稿箱 → 队列。不要去阿里后台填 40 个红星字段。

开通账号 → 授权自己的店 → 填一次店铺默认 → 投料（图 / 短表 / 提示词） → 草稿箱只审红黄项，看质量分 → 队列发布（失败原因是人话，改完重发）

0. 开通账号

打开工作台后先登录。没有账号就用管理员给的注册码开通。

已有账号

圈点哪里做什么
1工作邮箱填你的工作邮箱
2密码至少 8 位
—进入工作台黑按钮，进侧栏
3还没有账号？切到注册
4底部说明店铺用官方 OAuth，不收集阿里密码

第一次开通

圈点哪里做什么
1工作邮箱以后登录用这个
2密码至少 8 位
3注册码向管理员索取，填错进不去
4已经有账号回到登录

开通后如果还没有店，会先落到「店铺」页。

1. 授权自己的店铺

国际站上品必须用你自己店的 token。平台只拿 AppKey，店和店之间隔离。

圈点哪里做什么
1授权新店铺跳转阿里官方页确认，回来就是「已授权」
2店铺默认填一次产地、包装、付款，后面每条货自动套
3已授权绿标表示 token 可用。异常就重新授权

正式环境走官方授权。左上角店铺下拉切换当前店；投料、草稿、队列都只看当前店。

2. 填一次店铺默认（5.0 的依据）

这些是经营决策，AI 不准猜。填一次，后面每条商品自动套，也是信息质量分里「交易 / 物流」两桶的来源。

圈填什么为什么
1发布模式先「只发草稿」跑通，确认后再切「直接上架」
2产地、计量单位、物流、样品官方红星。产地不要让 AI 改
3运费模板、包装重量和尺寸缺了物流分到不了 5.0。没有运费模板就留空，走买卖双方协商
4付款、港口、发货期、品牌付款/港口/交期不准编。没有品牌就留空 = 无品牌

3. 概览：只推一条路

登录后日常从「概览」进。它按你现在的情况只推一个按钮，不要自己选流程。

圈是什么怎么用
1五步导航日常只走这 5 个，不要找商品库
2当前店铺先选对店再投料
3更快的起点 / 数字有红项先审；有可发布的去草稿箱
4去投料上品新店最常见：丢图 + 价格就能成稿

4. 投料：你填依据，AI 补其余

投料页有三条路，点顶部卡片切换。

4.1 有实拍图（最常见）

圈点哪里做什么
1三条路有图走这条；没图出提示词；批量走短表
2产品图1～6 张实拍。第一张是主图。至少 3 张才容易到 5.0
3货号 / 单价 / 起订量货号可留空。价和起订量是红线，AI 不定价
4补充可选。中文也行，例如「加厚款，可定制 logo」

点「生成草稿」。批量按货号命名：SKU-1001_1.jpg。

4.2 下载表格，填完传回

表在这一页下载，不是阿里后台那张 40 列表。填写页不加 Type / Color。

圈点哪里做什么
1你填 / AI 填 / 红线先看清谁写什么。粉的是红线
2选择叶子类目整表选一次。猜错发不出去、属性全废
3下载填写表短表：货号、单价、起订量、图片、品牌（选填）
4拖入图片按货号命名，或在表里填链接，再点批量成稿

4.3 没实拍：先出套图提示词

本平台不代生图。只出国际站 6 个槽位的提示词，复制到你自己的生图模型，出图后再走 4.1。

  • 可选类目模板；不选则按品名匹配
  • 写品名 / 货号，补充能看见的事实
  • 出 6 条：白底主图、尺寸、细节、场景、外箱、OEM
  • 不要让模型编 CE / FDA，不要往主图加字，不要加价格

5. 草稿箱：只审红黄，看 5.0

绿的可以勾上直接进队列。红、黄必须点开。

圈点哪里做什么
1红 / 黄 / 绿红拦发布；黄建议看（不到 5.0）；绿已过本地校验
2质量分官方六桶预估。5.0 才算齐
3一键选中 / 批量发布先勾绿的，再进队列
  • 红项：在官方选项里点一下，不要选 Other
  • 核单价和起订量；手改过的标题，重新成稿不会覆盖
  • 不到 5.0：按黄条补店铺默认或再补实拍

6. 队列：失败是人话，改完重发

  • 关掉页面不影响后台发布
  • 模式：官方草稿 或 直接上架（看店铺默认）
  • 失败原因已翻成中文。点「看草稿」改，再「重发」
  • 官方建议先用不超过 15 条测试，再大批量

你填什么，AI 填什么

谁字段说明
你，每条货实拍图、单价、起订量依据。没有图无法识别，也无法发品
你，建议货号、中文备注备注给 AI 当提示，不进官方标题
你，选填品牌空着 = 无品牌。AI 不准编品牌名
你，整表一次叶子类目红线。猜错发不出去
你，每个店一次产地、单位、付款、港口、交期、运费、包装、样品5.0 的交易/物流桶
AI英文标题、关键词、类目属性、详描、FAQ按图和官方选项。不选 Other，不编认证
系统图片银行、schema 校验、重铺预检外链图发不了

红线：这些不准交给 AI

  • 售价、起订量 — 生意决策，不准定价
  • 实拍图 — 不准用生成图冒充实拍
  • 品牌 — 空着=无品牌，不准编
  • 叶子类目 — 猜错发不出去，属性全废
  • 原产地、证书 / CE / FDA、运费、付款、港口 — 店铺默认或你自己填

要到 5.0：类目对、标题和 3 个关键词、必填属性对齐、价和起订量、付款和交期、包装尺寸重量、至少 3 张已入图片银行的实拍 + 详描。缺了会标黄，不会假装满分。

常见问题

授权报 Redirect uri does not match
开放平台登记的回调，必须和本服务的 /api/v1/alibaba/oauth/callback 完全一致。
投料提示先授权店铺
左上角先选一个「已授权」的店。
成稿后属性是红的
审稿时在下拉里选官方选项，不要选 Other。类目选错就先换类目。
质量分不是 5.0
包装和交期回店铺默认补；图不够再投实拍，不要用生成图凑数。
可不可以下官方 40 列表
可以，在投料页最下面「已有现成表」。默认请用我们的短表。
没图怎么办
投料 → 先出套图提示词 → 自己生图 → 再按「有实拍图」投进来。
