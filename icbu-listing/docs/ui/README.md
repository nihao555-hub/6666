# Auto Shoper UI · Twenty 设计稿

对照 Twenty CRM 的工作台语言。侧栏和 Logo 全站同一套。

## 日常导航（锁定，只要这 5 个）

```
[A] Auto Shoper
    当前店铺 ▾

  概览
  店铺
  投料
  草稿箱
  队列

头像  邮箱    退出
```

登录页用同一个 `[A] Auto Shoper / 国际站上品`。

不要加：商品库、刊登模板、在线商品、设置、收藏夹、工作流。  
这三页路由还在，只在概览判断「这条更快」时才打开。

## 傻瓜路径

授权店铺 → 填一次默认 → 投料（图 / 价 / 起订量）→ 草稿箱核对 AI 填的 → 队列。

## 视觉 token

| 角色 | 值 |
|---|---|
| 画布 | `#FFFFFF` |
| 侧栏 | `#F3F3F2` |
| 墨色 / 主按钮 | `#171717` |
| 次要 | `#716F6C` |
| 发丝 | `#EDEDED` |
| Logo | 黑圆角方块 + 白字 A |

主按钮是黑底白字。不要藏青侧栏，不要 Ant 蓝。
