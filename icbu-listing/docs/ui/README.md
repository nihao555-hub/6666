# Auto Shoper UI · Twenty 设计稿

对照 [Twenty CRM](https://twenty.com) 的工作台语言重画。  
**先定稿，再 1:1 改前端。** 本目录是实现依据，不是装饰图。

侧栏只保留现有业务入口，不抄 Twenty 的 People / Companies / Opportunities。

## 视觉 token

| 角色 | 值 | 用法 |
|---|---|---|
| 画布 | `#FFFFFF` | 主区、表格、侧栏面板 |
| 侧栏 | `#F3F3F2` | 浅暖灰，不是藏青 |
| 悬停 | `#EBEBEB` | 行、导航 |
| 选中 | `#E6E6E6` | 导航 pill、选中行 |
| 墨色 | `#171717` | 标题、主按钮 |
| 次要 | `#716F6C` | 说明、表头、占位 |
| 发丝 | `#EDEDED` | 分割、表格、输入描边 |
| 浅底 | `#F5F5F5` | 输入填充、折叠区 |
| 红 | `#C4564A` | 缺字段、失败 |
| 黄 | `#C48A00` | 建议换图、待确认 |
| 绿 | `#3A7D44` | 可发布、已授权 |

规则：

- 主按钮是黑底白字，不是 Ant `#1677FF`，也不是藏青块。
- 强调色占用面积 ≤ 10%。层级靠字号和间距，不靠加粗堆砌。
- 表格贴齐画布，不要套厚卡片、不要投影。
- 图标用细线（Tabler 一类），16px。
- 记录行高约 36px；点开一行用**右侧面板**，不要先弹大模态。
