# 用户流程（AI 少填 + 官方 Schema 发品）

原则：用户只提供机器推不出来的东西。类目、属性、英文标题、关键词、详情、图片银行、物流默认值都由系统和 AI 补。人只审红黄项和价格。

旧接口 `alibaba.icbu.product.add` 已不对新商家开放。发布必须走 Schema：

`schema.get` 拿规则 XML → 填 `itemParam` → `schema.add` 提交。

行业公理（领星）：**草稿 = 商品库（SPU）+ 刊登模板**。模板只填空，从不覆盖手填或已经填过的值。标题、图片、价格不是模板字段。

## 用户看见的几屏

日常导航只留傻瓜路径，避免选来选去：

```text
0. 概览     只推一条最快路径，点一个按钮
1. 店铺     授权 + 填一次产地 / 单位 / 物流 / 样品
2. 投料     实拍图 / 下载短表填完传回 / 提示词；人只出图、价、MOQ；类目属性交给 AI
3. 草稿箱   只审红黄项，绿的勾上进队列
4. 队列     发布中 / 成功 / 失败可改再发
```

这三页不进侧栏，概览判断需要时才打开：

```text
商品库     货已识别过、要铺多店
类目模板   少数类目要单独固化字段
在线商品   老店复制已过审品再差异化
```

不要做成阿里后台的 40 字段表单。

## 完整链路

| 步 | 谁做 | 用户填什么 | 官方接口 |
|---|---|---|---|
| 1 授权店铺 | 用户点一次 | 官方 OAuth 确认，不交密码 | `openapi-auth.alibaba.com` → `/auth/token/create` |
| 2 店铺默认 | 用户填一次 | 询盘/一口价、币种、港口、付款、交期、运费模板、包装 | `product.group.get`；运费模板来自 schema 选项 |
| 3 入库 / 投料 | 用户每条做 | **图**；建议货号、FOB/售价、MOQ | 无（图先进本地商品库） |
| 4 看图理解 | AI，每个 SPU 一次 | 无 | 无（多模态模型） |
| 5 铺到店铺 | 用户勾选 | 选哪些店；可选差异化文案 | 每店各自 `/alibaba/icbu/photobank/upload` |
| 6 预测叶子类目 | AI，低置信度才问 | 偶尔选一下类目 | `/icbu/product/category/get` + `schema.get` |
| 7 拉发布规则 | 系统 | 无 | `/alibaba/icbu/product/schema/get` |
| 8 属性对齐 | AI，对不上标红 | 点选对不上的属性 | 无（对 schema option） |
| 9 写英文内容 | AI | 无；多店时换卖点角度 | 无，但必须过 schema 规则 |
| 10 套模板 | 系统 | 无 | 只填空，不覆盖标题/图/价 |
| 11 审稿 | 用户 | 确认红黄项，核对价格/MOQ | 无 |
| 12 排队发布 | 系统 | 点发布 | `/icbu/product/schema/add` 或 `schema.add/draft` |
| 13 在线商品 | 只读 | 看已上架 | `schema.render` / `product.list` / `product.get` |

## 用户每条商品最少填什么

必给：1～6 张图。  
建议给：货号、价格、MOQ。  
可以不给：标题、关键词、属性、详情、港口、付款、交期、运费模板。

批量短表在「投料 → 下载表格，填完传回」下载。不是官方 40 列表，填写页不加 Type / Color。
整表选一次叶子类目（红线，AI 不准猜），属性由 AI 按官方选项补。

红线（不准交给 AI，给了会出问题）：

- 售价、起订量 — 生意决策，AI 不准定价
- 实拍图 — 不准用生成图冒充实拍
- 品牌 — 有品牌你填；空着=无品牌。AI 不准编品牌名
- 叶子类目 — 整表选一次，猜错发不出去、属性全废
- 原产地、证书/CE/FDA、运费模板、付款、港口 — 店铺默认或你自己填

价格和 MOQ 是生意决策，AI 不代填。没有图就无法识别，也发不了品。

没实拍时：投料页「套图提示词」按类目出 6 条提示词，复制到你自己的生图模型，出图后再投料。本平台不代生图。

多店时图只丢一次。商品库勾店铺铺货，不会对每个店重新看图。

## 套图提示词（按类目，只要词不要图）

国际站图片银行最多 6 张。我们只产出提示词，生图在卖家自己的模型里做。

槽位：白底主图、尺寸/规格、细节、使用场景、外箱、OEM。不编认证、不加价格、主图无字。

类目模板：文具画材、五金刷具、消费电子、服装鞋包、美妆、家居、玩具母婴、饰品、机械、食品、运动、通用。

## Schema 字段怎么分

店铺默认 / 刊登模板（填一次就套用，只填空）：

- `market` 询盘=2 / 一口价=1
- `priceUnit` `paymentMethod` `port` `ladderPeriod`
- `shippingTemplateId` `pkgMeasure` `pkgWeight`
- `logisticsMode` `logisticsProperty`
- `origin` `marketSample`

AI 生成：

- `productTitle`（≤128 字节，禁中文/邮箱/HTML）
- `productKeywords`（1～3 个）
- `icbuCatProp`（必须对齐官方 option）
- `superText` / `productDescType`
- `scImages`（先 upload，再写 url + fileId）

用户每条确认：

- `fob` 或 `ladderPrice` / `scPrice`
- `minOrderQuantity`

## 审稿规则

- 绿 ≥0.85：自动采用，折叠
- 黄 0.6–0.85：预填，可略过
- 红 <0.6 或必填空：必须点一下

类目选错后面属性全废。前 20 条建议看一眼，同类目记住后不再问。

平台按「标题 + 属性 + 图片」打重铺。同一 SPU 铺到第二家店起会换文案角度，并在提交前做本地重铺预检。

## 现在做到哪

做到第 12 步：授权 → 默认 → 入库/投料 → 商品库铺多店 → AI 成稿 → 模板填空 → 审红项 → `schema.add` 发询盘品。

Excel 导入：默认走我们自己的短表，不抄官方 40 列。

- **短表（投料页下载）**：只填货号、价、起订量、图、品牌。标题/属性交给 AI。价/图/品牌/类目是红线
- **领星资料库**：表格是 SPU 资料，先入库再铺店
- **店小秘按刊登模板**：表格只填差异字段，类目 / 物流走模板，导入进草稿
- **智能探测**：任意表头（通途 / 自己的表），找表头并对列，确认后再导
- **马帮库存SKU导出**：按马帮列名预设映射

字段带来源（手改 / Excel / AI / 模板 / 店铺默认）。重新成稿和套模板不会覆盖手改或 Excel 填过的值。

上品前按卖家**当前情况**选最快路径，而不是人人走同一张表：

| 你现在的情况 | 最快路径 | 对照官方 |
|---|---|---|
| 还没授权店铺 | 先 OAuth | 官方批量上传也要先登录自己的店 |
| 有红项草稿 | 先审红项 | 官方也是先检测再导入 |
| 有可发布草稿 | 入队 | 官方建议先 ≤15 条测试 |
| 店铺默认没填 | 填一次，或从在线品反推 | 官方 Excel 红星：运费模板、单位、包装 |
| 商品库已有货 | 勾店铺铺货 | 官方还要再填一张类目表 |
| 店里已有不少在线品 | 复制并差异化 | 官方可复制商品；我们回读 schema.render，AI 换标题防重铺 |
| 新店只有实拍图 | 投料看图成稿 | 官方要先选类目再下 Excel |
| 没实拍 | 先出 6 条套图提示词，自己生图再投 | 官方仍要你先有图再导入 |
| 已有 Excel / 别的 ERP 表 | 投料页下载短表，或选领星/店小秘/马帮表 | 官方 40 列红星表我们不抄 |

还没做：一口价 SKU 笛卡尔积、定时发布、子账号角色、经营大类购买向导。
